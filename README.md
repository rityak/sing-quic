# sing-quic

Протокол hysteria2.

Форк [metacubex/sing-quic](https://github.com/metacubex/sing-quic) для [miray](https://github.com/rityak/miray). Наш код — в ветке `miray`.

## Что изменено

- Клиент hysteria2 обрабатывает принятые датаграммы по порядку. Раньше на каждую запускалась горутина, и датаграммы одного потока приходили переставленными.
- Заголовок UDP-сообщения hysteria2 пишется и читается напрямую, без рефлексии: на датаграмму меньше аллокаций, UDP через hysteria2 дешевле по CPU на ~9% (бенчмарк в одном процессе). Формат тот же.
- Обфускация Salamander без аллокации на пакет: XOR идёт словами, ключ считается без копии в куче, буферы из пула. TCP через hysteria2 с Salamander дешевле по CPU на 30%, UDP на 15% (бенчмарк в одном процессе). Формат тот же.
- Linux: Salamander больше не выключает в quic-go GSO, пачечный приём и GRO — каждый сегмент пачки получает свою соль, на проводе это обычные датаграммы Salamander. TCP через hysteria2 с Salamander дешевле по CPU вдвое (бенчмарк в одном процессе). Выключается `MIRAY_SALAMANDER_OOB=off`.
